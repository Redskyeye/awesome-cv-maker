# Awesome CV Maker [![](https://awesome.re/badge.svg)](https://awesome.re)

> 收集全球最好用的简历制作工具、AI 优化助手和简历模板。

## 🌟 我的推荐 (Featured)
* [CVS](https://github.com/Redskyeye/CVS) - AI 简历优化助手：结合 AI 技术，快速生成专业、针对性的优化简历。

## 🤖 AI 简历助手 (AI-Powered)
* [ChatGPT](https://chatgpt.com) - 强大的 AI 对话模型，可用于内容润色。
* [JobEmerge](https://www.jobemerge.work) - AI 求职助手，提供岗位匹配分析、19 种语言简历翻译、Markdown 编辑和文字模拟面试。
* [ReactiveResume](https://github.com/AmruthPillai/Reactive-Resume) - 开源、免费且尊重隐私的简历制作工具。

## 📄 简历模板 (Templates)
* [Deedy-Resume](https://github.com/mzyy94/Deedy-Resume-OpenFont) - 经典的单页简历 LaTeX 模板。

## 🛠 开发工具 (Developer Tools)
* [Markdown-to-PDF](https://github.com/yzane/vscode-markdown-pdf) - 将 Markdown 简历转为 PDF。
